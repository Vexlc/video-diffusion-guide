跟一段方块学三件事

看下面的原片。每格是一帧，方块从第 7 列出发，每帧向右一格。六帧一共含有 1,152 个像素。编码器把它们压成 72 个数，再用训练集的均值和尺度统一量纲。我们只跟其中一个数，看看训练怎样出题，生成又怎样落笔。

① 已经有原片，怎样出练习题？

把选中那一格的原片数值叫 y，抽到的噪声叫 z。两道练习共用这对端点。横向进度 t 从纯噪声的 0 走到原片的 1。

扩散题 · 猜混入的噪声

x = a·y + σ·z

直线流匹配题 · 猜速度

x = (1−t)z + t·y

扩散题采用一种保方差的示例日程，a = sin(πt/2)，σ = cos(πt/2)，所以 a² + σ² = 1。每个点单独表示该噪声量下的训练输入，画曲线时固定了同一份 z。这个小视频生成器实际练的是右边的速度题。

网络同时读取整段的 72 个数、进度、方向和首帧点图。下面沿着块 7 的分量 0 对一次答案，块号和分量号都从 0 数起。

② 没有原片，下一步怎么走？

生成器只拿到噪声、进度和条件。它读自己上一步留下的状态，猜速度，再往前走 1/24 个时间单位。许多练习题会经过附近，网络学着给出这些题的平均方向。绿色实线记录它跟着所学方向走出的路线。

同一个模型，两次回答各做什么？

横着读胶片，时间过去了五个帧间隔。点“下一步”，改变的是整段影片的生成进度，六帧会一起重新解码。

③ 只把点下移，视频会怎样？

点“看成片”，先记下第一帧和最后一帧的中心，再选第 7 行。生成器两次都从同一份噪声出发，方向都选向右，唯一换掉的输入是首帧点图。上方练习也会随之换成对应的原片。

首帧提示点的位置

网络把点图编码成特征，由训练过的支路在两个位置修正基座特征。这是借用 ControlNet 思路的微型 DiT。原版 ControlNet 将控制支路接入图像扩散 U-Net。
