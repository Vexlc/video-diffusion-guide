倒放成片，还是重新生成？

想让方块向左走，可以倒放一段向右片，也可以把“向左”交给生成器。先猜一猜，两种做法的第一帧会从同一列出发吗？

沿四排胶片读两种速度

第一排从 (7,3) 向右生成。第二排逐字节沿用第一排的画面，只交换播放顺序。第三排保留起点、把生成指令改为向左。第四排沿用向左指令，把提示点挪到原路线的终点 (12,3)。三次生成使用相同权重和同一份起始噪声，各走 24 步。

橙框跟着播放格走。每格下面是最亮 3 × 3 窗口中心的实测列号。点击“从头播放”会按当前帧率播放一遍；本页回放的是 CPU 小模型的记录。

查看生成这格潜码时做的加法

每次取归一化生成进度的 1/24，做 x下一步 = x当前 + u/24。这里始终读块 8 的分量 1，u 的单位是“潜码单位／单位生成进度”。

轨迹重合，哪些像素还有差异？

左图取倒放片，中图取移动起点后重新生成的向左片。两张图按相同播放格、相同屏幕位置对齐。右图把亮度不同的位置涂成橙色，只要相差 1 就会着色。

蓝框标出读数位置。可以点图选位置，也可以用列和行选框。亮度采用 8 位显示值，范围是 0 到 255。

进入离线包的 reproduce 目录。第一条命令用 Python 标准库复算书中成绩，第二条用 PyTorch 和随包权重重新生成三段片及本页。把 9317 换成其他整数即可测试新噪声。
