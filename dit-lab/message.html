一条消息怎样穿过视频帧？

白方块从右向左移动。小模型把六帧压成三个时间组，每组切成六块。先看中间的块 8，它在一次预测中能从最后两帧读到多少信息？

选择谁读、读谁

绿框是接收消息的查询块。点击一个格子，把它选为发送信息的源块（橙色）。两种颜色可以落在同一块上。

原片显示位置变化。下面的网格画压缩后的块地址。相邻两帧会一起编码，一个潜块的特征可能包含周围像素。

从 Q 和 K 算出这个百分数

同一个头里的 Q 和 K 各有 16 个分量。选一个编号看乘法，再把 16 个乘积相加得到匹配分数的分子。

softmax 将每个允许的分数取指数，再除以它们的总和。先把整行分数减去同一个最大值，可以保持比例相同并使数值计算稳定。

只改源块交出的一个数

保持输入、方向和进度不动，在第一层第一个注意力头中，给源块的值向量 V 的分量 0 加 1。Q 和 K 保持原值，因此这一层采用相同的权重。下面显示模型重跑时读到的数。

整网报出的速度分量

读数取自生成进度 0.5 的一次查询。速度是所选潜块的第 0 个输出分量。注意力头先汇总消息，再经过输出投影、残差连接、第二层和输出层，网络才给出这个速度。

用 Python 复算这格，或用模型权重重做干预

在解压包的 reproduce 目录运行。第一条只需 Python 标准库，会同时列出原值与加 1 后的实测。第二条用 CPU 版 PyTorch 载入随包权重，重新执行全部前向。若要读取自己的记录，给第一条补上 --record replay/attention/message.json。

python3 attention_capture.py --out replay/attention/message.json
