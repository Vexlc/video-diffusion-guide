怎样读这三个指标？

每帧像素误差：每帧可以独立找最像的合法方块图。整片像素误差：同一条合法路线必须解释全部六帧。严格命中：每帧最亮的 3×3 窗口中心必须逐帧等于某条合法路线；并列时取行优先的第一个位置。前两项用未裁剪像素的均方误差。

自己复现：在 reproduce 目录运行 python pixel_lab.py --device cpu --replay ../pixel-lab/weights.pt 从权重重新采样；去掉 --replay 及其路径就从零训练。此可选脚本需要 PyTorch；只看本页不需要安装。查看 numbers.json 可核对未舍入指标。
