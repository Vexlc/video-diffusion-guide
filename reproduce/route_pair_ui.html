同一份噪声，四段影片

每段只有六帧。请方块沿第 3 行走，先看扩散模型交出的两段影片，再看流匹配模型。把目标改成第 7 行之前，猜猜哪两段会跟着换行。

哪一段听了位置提示？

横读一条胶片，从左到右是帧 0 至 5。青块是生成结果，橙色虚线是指定行。六帧的中心都落在虚线上才算整段命中。

训练时，这一格要猜什么？

只看首帧的纵坐标。我们用 −1 表示第 3 行，+1 表示第 7 行。出题时，干净值 y 和噪声 z 都已知。拖动进度，看看两位“出题老师”把什么交给网络，又拿什么给它打分。

扩散 · 猜混合量 v

x = a y + σ z，答案 v = a z − σ y。
a = sin(πτ/2)，σ = cos(πτ/2)。

直线流匹配 · 猜速度 u

x = (1 − τ)z + τ y，答案 u = y − z。
这对起点和终点连成一条直线，速度恒定。

生成时，模型真的往哪走？

从同一个 z 出发，模型连续作答 24 次。下面跟踪所选影片的首帧纵坐标。此处的 x 是前面几步走到的位置。模型只能看到当前状态、进度，以及开启时的位置提示。

位置修正怎样接入两台生成器？

每个基座一起读取六帧的 12 个坐标，学习后冻结。复制两层作为支路，让它额外读取首帧行号 c。在主干的特征 h 上加一份修正，得到 h′ = h + λ r(x,τ,c)，再预测 v 或 u。出口权重和偏置从零开始，训练后开启 λ 就能改变整段轨迹。这里用行号演示接线；讲义第 85–86 页展示原版视频项目怎样接收二维深度图。

换一批噪声，也会听提示吗？

64 份测试噪声各配第 3 行和第 7 行，共 128 道题。左右方向由生成器决定。训练数据只有上下两行、每行左右两个方向，考试换了噪声，路线仍是这四种。

用 Python 对答案

在完整离线包的 reproduce 目录运行 python3 route_pair.py --seed 1700 --row 3 查看四段影片的六帧中心，运行 python3 route_pair.py --cohort 核对整批。两条命令只用标准库。
