去噪流匹配视频控制
用自己的参数画四张图 · 只需 Python 3

下载 first_lab.py，在保存它的文件夹打开终端。解压包里的同一个脚本放在 starter-lab 文件夹。以下命令在 macOS 或 Linux 中运行；Windows 安装了 Python 启动器时，将开头的 python3 换为 py -3。若本机用 python 启动 Python 3，也可用这个名字。

python3 first_lab.py --out before.html
python3 first_lab.py --noise-error 0 --out after.html

双击两份网页。第一张图最右边橙框的亮度应从 0.6875 变成 0.8000。另三张图沿用原来的参数，可以逐张对照。每份网页都能单独复制到别处打开。

再试一次流匹配。运行下面这行，然后打开 two.html。看第二张图的橙线，猜它能不能到达目标行 +1。

python3 first_lab.py --steps 2 --out two.html
核对流匹配终点

同样从 0.4 起步，一步到 0，两步到 0.3799，默认十二步约到 1。在自己画的两步图下面展开“把橙线的一步拆开算”。第一步速度 −0.4000，走半步到 0.2000。此时速度变成 +0.3599，第二步就转向了 +1。
