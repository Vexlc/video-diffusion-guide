u 是 0 到 1 的均匀抽数，ξ 是新抽的标准正态数，两者独立。手算选项指定其数值；按种子重抽时两种随机走法共用 ξ。灰度以 −1 到 +1 显示，旁边是裁剪前的数。

一次反向步的系数从哪来？

把较干净层记为 j，当前层为 k。正向走法是 xₖ = r xⱼ + √β ξ，r = aₖ/aⱼ，β = 1−r²。若知道原值 y，两次读数是联合高斯。固定观测 xₖ 后，xⱼ 的条件中心是 cᵧ y + cₓ xₖ，共同方差为 s²。

其中 cᵧ = aⱼ β / σₖ²，cₓ = r σⱼ² / σₖ²，s² = β σⱼ² / σₖ²，σ² = 1−a²。只知道带噪读数时，两种来源按第 8 页的后验概率混合。DDPM 一栏用这个共同方差和预测均值，DDIM 一栏用 aⱼ ŷ + σⱼ ε̂。

二 · 固定输入时的下一层

均值一样，亮度会落在同一处吗？

每一对柱子比较同一亮度区间所占的概率。窄格宽 0.15，左右尾部也各算一组。纵轴随设置调整；看柱高是否相等时，请在同一张图内比较。

条形总长固定，橙色表示已知来源后组内方差的占比，绿色表示两组中心不同造成的占比。直接走到干净层时，组内扩散宽度为 0，两种干净原值仍有不同的概率。
