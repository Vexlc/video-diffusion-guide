模型猜亮度或速度，调度器用这个猜测更新整段影片。先动一次时间滑块，再点一格，看库实际返回的数和自己代公式的数是否相合。

第 13 次更新时，看帧 2 的第 8 行、第 10 列。把干净猜测限制到 [−1, 1]，看看下一格会往哪个方向变。

二、噪声钟倒着走，速度要怎样填？

首帧点在第 7 列、第 3 行，方向向右。模型给出生成进度每增加 1 的变化量 u。调度器按照剩余噪声 σ 走，σ 从 1 减到 0。选一格潜码，沿两个方向各走一步。

让 CPU 重跑同一份记录

网页逐格读取随包网络与 Diffusers 0.35.1 的实测输出，并用 JavaScript 重新计算公式。解压后进入 reproduce 目录，第一行只需 Python 标准库。要重新运行两个神经网络，可在已有 PyTorch 的环境安装固定版本的库，再执行第三行。

python3 scheduler_report.py --kind flow --step 13 --index 30
python3 -m pip install diffusers==0.35.1
python3 scheduler_bridge.py --out replay/schedulers.json
python3 scheduler_report.py --record replay/schedulers.json --out replay/scheduler-lab
