把作者函数的两个端点交换，能看出来吗？

拿第 7 页的同一格车身做题。雪花是 −1，原片亮度是 +0.8。在作者库的直线路径 CondOTProbPath 中，x_0 表示出发端，x_1 表示目的端。上排从雪花出发，下排交换两个参数。

圆点标出当前题面 x_t，短箭头标出速度 dx_t 的方向。把进度拖到 0.25，再拖回 0.50。半程交换端点，两排题面相同，速度却从 +1.8 翻到 −1.8。训练时若把端点写反，同一张半程输入就会配上相反的监督标签。

用作者代码复算

页面保存了作者库在 CPU 上返回的 101 个进度、两种顺序的实际读数。进入学习包的 reproduce 文件夹，运行第一行可离线读取并用公式核对。若已安装作者的 flow_matching 和 PyTorch，第二行会在本机直接调用作者函数。

python3 author_endpoints.py --step 25
python3 author_endpoints.py --step 25 --official

有现成的 PyTorch 环境时，可以直接运行下面的完整例子（还需安装上述作者库）。

import torch
from flow_matching.path import CondOTProbPath

path = CondOTProbPath()
z = torch.tensor([[-1.0]])
y = torch.tensor([[0.8]])
t = torch.tensor([0.5])
for start, end in [(z, y), (y, z)]:
    answer = path.sample(x_0=start, x_1=end, t=t)
    print(round(answer.x_t.item(), 3), round(answer.dx_t.item(), 3))
