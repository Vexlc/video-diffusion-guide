看不同训练量学出的路牌

纵轴是运动系数在生成时间里的变化率，不是影片中小车的车速。曲线的每个点是一个位置上的模型回答。

实验 H　·　PDF 第 27–28 页

同一起点重跑，最后还是同一条路线吗？

固定起始噪声，滑动重跑编号：先用 DDIM，再改用 DDPM。每一格都是从同一个预测器真实算出的车心。选择“换起点”，改变的是另一种随机来源。

自己重算

本页是 Python 新算出的固定样本和训练检查点，不在浏览器里重新训练。打开复现包的 reproduce 目录，运行 python3 workshop.py；或试试 python3 workshop.py --samples 0 --updates 0。每次都会生成一份可单独带走的 HTML。
